# Inversion Estimate - option 'many'

This function should be preferred when there are many inversion
estimates to be computed.

## Usage

``` r
inversionEstimate_BD_many(n, obs_nb_cycles, cyc_all = NA)
```

## Arguments

- n:

  An integer: The number of markers. A marker represents an aligned
  block, a gene, or any other genomic region being rearranged.

- obs_nb_cycles:

  An integer: The observed number of cycles in the breakpoint graph of
  two genomes.
