# Connected components

Connected components of the breakpoint graph.

## Usage

``` r
components_graph(g, p_extended)
```

## Arguments

- g:

  The breakpoint graph.

- p_extended:

  The extended permutation.

## Value

Connected components of the breakpoint graph.
